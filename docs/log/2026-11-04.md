# Work log — 2026-11-04

## Metadata timestamps — 2026-11-04

Added HFS+ timestamps to the writer. `struct hfs_catalog` now carries a
`now` value in HFS+ epoch seconds; `create_object` sets create/access/content/
attribute dates on new file and folder records, and `update_valence`, append,
truncate and rename touch the content/attribute dates. `backupDate` stays 0
until a backup tool records one. The volume header modify date is staged on
create/delete and on bitmap alloc/free. Added a host timestamp test covering
create, parent-folder touch, append, truncate, delete and volume modify date.

The write diagnostic now passes the 6G RTC time into the inner catalog; if the
RTC read fails it falls back to 0 and leaves dates untouched.

Current image after the timestamp/RTC change: 110,920 bytes, SHA-256 `81350f…`,
DFU 119,056 bytes, SHA-256 `ce356e…`. Host tests: 108 portable (96 HFS+, 12
bootloader), sanitizer-clean; write-diagnostic outer/inner test passes.

Still open: BSD owner/group/flags, Finder info/prototype, a timestamp policy for
updates, and a macOS differential corpus (T-044).
