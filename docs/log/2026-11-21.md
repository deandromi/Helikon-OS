## Learned

- A whole-buffer codec contract is not just a memory limit: it makes the VFS
  read path unusable, because `hfs_fork_read` is offset-addressed and never
  hands out a mapped window. The source model is the cheapest seam that fits
  both.
- A probe that sees only a head needs a way to say "not yet"; conflating that
  with `FORMAT` either rejects valid files or forces every probe to be
  whole-file. `NEED_MORE` plus "open is authoritative" keeps both honest.
- The verification matrix in the previous handoff listed nine suites; two more
  exist and had been broken for three days. The matrix should be derived from
  `tests/*/Makefile`, not from memory.

## Rejected

- Making every decoder streaming in one change: FLAC and MP3 need buffer
  semantics (frame indexing; libmad `main_data` boundaries) and would have
  turned one reviewable seam into three half-converted decoders.
- A seek-taking source: `read_at` with absolute offsets already matches the HFS+
  and block layers and needs no state in the source.
- Stub `helikon_mp3_codec_ops` for the player/UI suites: it would hide a real
  link requirement and drift from the registry.
