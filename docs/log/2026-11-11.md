## Learned

- The 6G Apple limit is LBA28/128 GiB, while the Rockbox `ipod6g` port uses
  `HAVE_LBA48`; the Helikon ATA path has several LBA48 gaps and must be probed
  before a writable LUN is built.
- The 6G/iFlash MBR may store partition start/size in 4096-byte units; the APM
  parser also needs a real-device check.
- `select_partition()` already chooses the largest HFS+ partition, which makes a
  second larger data partition the safest capacity migration.

## Rejected

- A writable LUN in the normal firmware profile; it would create two writers.
- A separate Disk Mode firmware image; the loader has one image path.
- A bootloader USB write mode; the bootloader stays read-only.
