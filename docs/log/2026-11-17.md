## Failures (T-097 + MP3)

- Zero-PCM decode: root cause was `sbsample`/`sbsample_prev` pointing at
  separate buffers (the aliasing is Rockbox-single-core load-bearing).
- SIGSEGV in host tests: clang idiom-recognition × freestanding mem shims
  → unbounded recursion; fixed by `HELIKON_HOST_TEST`.
- Post-seek silence: stale `synth.pcm.length` (cleared) plus empty
  `main_data` reservoir — `BADDATAPTR` frames until the chain rebuilds;
  the vbr fixture was enlarged so the resume is observable in tests.
- Probes misfiring on FLAC garbage: lone plausible headers inside
  corrupt streams; fixed by chain corroboration in the probe.
- GCC sign-conversion error on `head->crc` bit extraction; fixed with an
  explicit `(uint8_t)` cast. An intermediate `sed -i` batch edit silently
  no-opped; source edits done with the edit tool only.

## Learned (T-097 + MP3)

- libmad's dual-core pointer-swap code path is the only place the
  two-buffer wiring is correct; single-core (Helikon, Rockbox) requires
  aliasing.
- `HAVE_LIMITS_H` cannot be set under `-nostdinc`: layer12/layer3 fall
  back to `CHAR_BIT`-derived limits unless the shim supplies them.
