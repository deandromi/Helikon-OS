## Learned

- Rockbox's codec libs moved to `lib/rbcodec/`; Helikon docs citing
  `apps/codecs/` need the translation.
- libm4a is Hammerton-MIT + Chapman GPL-2+, not ffmpeg-derived as first
  guessed; libfaad must stay pinned to the 2005-02-02 CVS snapshot.
- AAC-LC's likely 256–400 KiB workspace is the first collision with the
  128 KiB `HELIKON_CODEC_WORKSPACE_MAX`; resolution is measurement, not
  pre-reservation (`audio-formats.md` §12.4).

## Rejected

- Copying Rockbox's disk-loaded `.codec` mechanism, shrinkable whole-DRAM
  audiobuf, malloc-facade and three-thread pipeline — incompatible with I-14,
  ADR-0003 and the cooperative runtime (`audio-formats.md` §12.3).
- Apple's Apache-2.0 ALAC reference decoder (would force GPL-3), minimp3/
  dr_mp3 (float), Helix (RPSL), fdk-aac (licence/C++) for the first ports.
